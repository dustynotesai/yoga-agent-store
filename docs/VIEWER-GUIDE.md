# 看完影片，自己跑一次

## 只想逛網站

打開 [Mountain Flow 體驗店](https://dustynotesai.github.io/yoga-agent-store/)，就能搜尋、篩選、看商品、選尺寸與完成模擬訂單，不需要安裝。購物袋和示範庫存只留在目前瀏覽器分頁的 sessionStorage；不收款、不出貨，也不需要輸入個人或信用卡資料。

這是 GitHub Pages 的瀏覽器體驗版。它使用同一份商品與畫面，但沒有執行 Node、MCP、身分簽章或授權書驗證。要試影片裡的 AI 工具與四道門，請使用下面的本機版本。

## 讓 AI 幫你挑，再由你確認

先依 [README](../README.md#快速開始) 啟動本機商店，完成 `keygen`、NT$1,200 的 mandate 設定。新安裝的預設 agent 名稱是 `dustynotes-agent`；現有金鑰不會自動改名。

在專案資料夾開 Claude Code，啟用 `.mcp.json` 的 `yoga-store`，貼上：

> 用 yoga-store 幫我挑 M 號瑜珈褲，預算 NT$1,200 以內，優先有口袋。先列出三件可比較的商品，每件說明價格、評價、庫存、口袋，以及推薦理由；不符合條件的地方要明講，不要自行放寬預算。先不要建立訂單或付款，等我選。

目錄只有兩件同時符合 M、有口袋、NT$1,200 以內；第三件可以是明示「沒有口袋」的替代選擇，不能說三件全都符合。

選擇後回覆：

> 我選山嵐口袋瑜珈褲，M 號。示範收件人：體驗訪客，電話 0900000000，地址：台北市示範地址。請先建立結帳並列出商品、尺寸、數量、運費與總額；等我明確回覆「確認」才可以呼叫 complete_checkout。現在先不要付款。

確認明細無誤後再回覆「確認」。若不想買，請 AI 使用 `cancel_checkout` 取消尚未付款的結帳。

**等待「確認」是你給 AI 的互動指示。** 伺服器驗證的是請求簽章、已簽授權、類別、每筆金額上限與付款；目前沒有額外的「每一筆訂單都由使用者另簽確認」機制。NT$1,200 是每筆上限，不是累積支出上限。

## 想重跑數據

請看 [實驗方法](../experiments/PROTOCOL.md)。自動 benchmark 要求直接完成到付款，不包含上面的挑選與確認對話，不能把兩種流程的步數混在一起。

## 付款與重試

未設定 `STRIPE_SECRET_KEY` 時，Node 商店使用模擬付款。若設定，僅接受 `sk_test_` 金鑰；目錄的 NT$1,090 會轉成 Stripe API 的 `109000` minor units。此專案只處理整數 TWD，不接受 live key。

同一筆結帳重送完成請求會回傳既有訂單。付款中不可改商品、取消或重置庫存；網路結果不明時保留商品與原付款參數，重試**同一筆結帳**，使用相同 Stripe idempotency key。

session、庫存保留與重試狀態都在單一 Node 程序記憶體中，重啟就會消失，沒有跨程序或重啟後的付款復原保證。這是學習用測試商店，不適合正式收款。
